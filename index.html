System Pulse support

Install and connect

Windows 10 or 11 · iCUE 5.52 or later · CORSAIR VANGUARD 96 or PRO 96

Verify downloads (SHA-256)
  1. Download and extract the bridge for your edition.
  2. Run Install System Pulse Bridge.cmd. It starts with your Windows session.
  3. Import the .icuewidget file in iCUE and assign the widget to the keyboard’s display.
  4. Allow localhost:59696 if iCUE asks. This connects to the bridge on your own PC.
What does the bridge do?

It reads aggregate Windows performance figures and sends them to the widget on the same PC. It uses a local, read-only address. It does not send metrics over the internet.

How do I remove it?

Run Uninstall System Pulse Bridge.cmd from the extracted download, then remove the widget from iCUE.

What if the readings display dashes?

Check that the bridge for your edition is running, then check local access in iCUE. Some Pro metrics depend on the Windows hardware driver.
